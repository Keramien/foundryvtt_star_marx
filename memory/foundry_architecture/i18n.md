# i18n — Localisation / Traduction

> Système natif de Foundry pour supporter plusieurs langues.

---

## Principe

Aucun texte visible par l'utilisateur ne doit être codé en dur. Tout passe par des **clés de traduction** qui pointent vers des fichiers JSON.

---

## Déclaration dans system.json

```json
{
  "languages": [
    {
      "lang": "fr",
      "name": "Français",
      "path": "languages/fr.json"
    },
    {
      "lang": "en",
      "name": "English",
      "path": "languages/en.json"
    }
  ]
}
```

## Convention de nommage des clés

```
STARMARX.Section.SousSection.Clé
```

| Préfixe                      | Usage                        |
|------------------------------|------------------------------|
| `STARMARX.System.*`         | Noms généraux du système     |
| `STARMARX.Actor.*`          | Types et labels d'acteurs    |
| `STARMARX.Item.*`           | Types et labels d'objets     |
| `STARMARX.Attributes.*`     | Attributs de personnage      |
| `STARMARX.Skills.*`         | Compétences                  |
| `STARMARX.Roll.*`           | Messages de jets de dés      |
| `STARMARX.Sheet.*`          | Labels de la fiche           |
| `STARMARX.Chat.*`           | Messages chat                |

## Utilisation

### Dans le JavaScript

```javascript
// Traduction simple
const label = game.i18n.localize("STARMARX.Attributes.Strength");
// → "Force" (en français)

// Traduction avec variables (interpolation)
const msg = game.i18n.format("STARMARX.Roll.Success", {
  name: "Camarade Zorg",
  skill: "Pilotage"
});
// → "Camarade Zorg réussit son test de Pilotage !"
```

### Dans les templates Handlebars

```handlebars
{{!-- Traduction simple --}}
<h2>{{localize "STARMARX.Attributes.Title"}}</h2>

{{!-- Utilisable dans les attributs HTML aussi --}}
<input type="text" placeholder="{{localize 'STARMARX.Sheet.SearchPlaceholder'}}" />
```

---

## Résumé

1. Déclarer les langues dans `system.json`
2. Créer les fichiers JSON avec des clés hiérarchisées `STARMARX.*`
3. Utiliser `game.i18n.localize()` en JS et `{{localize}}` en Handlebars
4. Jamais de texte en dur dans le code ou les templates
