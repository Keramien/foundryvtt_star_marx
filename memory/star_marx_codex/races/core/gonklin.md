# Gonklin

> Source : Livre de base, p.87-88

## Description
Ressemblent aux humains mais avec une crête osseuse sur le postérieur qui détruit les chaises. Primitifs qui traitent les machines comme des animaux.

## Traits culturels
Illettrés technologiques qui détruisent les machines. Voyagent en "stop" (piratent les vaisseaux des autres avec leurs troupeaux de chèvres). Font des barbecues à l'intérieur des vaisseaux.

## Doctrine
**Marteau** (certains chasseurs plus faibles peuvent être Etoile).

## Signe Racial (obligatoire)
- **+2 pour casser** n'importe quelle machine
- **-2 pour utiliser** n'importe quelle machine

## Clef Raciale Obligatoire
Les Gonklins traitent les machines comme des animaux (chevaucher une voiture sur le toit avec les ceintures comme rênes, essayer de traire un distributeur Kolkha Kola...). 1 Zloty si la table rit, 1-3 Zlotys si le MJ l'utilise pour causer des problèmes.

## Signes Réservés
- **Toi, j't'aime pas** : peut intimider les machines (caméras, métros, pompes à carburant) avec un jet de BRISEUR DE GREVES
- **Toi, j't'aime vraiment pas** : pour des Zlotys (négociés avec le MJ), peut détruire complètement n'importe quelle machine

## Effets mécaniques résumés
| Effet | Valeur |
|---|---|
| Casser des machines | +2 |
| Utiliser des machines | -2 |
| Doctrine | Marteau (pref), Etoile possible |
