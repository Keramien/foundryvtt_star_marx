# Baboulin

> Source : Livre de base, p.92

## Description
Mercenaires colossaux avec d'énormes yeux en soucoupe.

## Clef Raciale Obligatoire (Galanterie babouline)
Les mâles ont un respect craintif envers les femelles (de toute espèce) car ils sont battus par leurs compagnes plus grandes depuis l'enfance. Les Baboulines femelles sont misandres. 1 Zloty pour les rires, 1-3 du MJ exploitant cette clef.

## Signes suggérés
"Grand", "Esprit de groupe"

## Effets mécaniques résumés
| Effet | Valeur |
|---|---|
| Clef Galanterie | Obligatoire |
| Signes suggérés | Grand, Esprit de groupe |
