# Truizyik

> Source : Livre de base, p.94

## Description
Nemtsyi porcins qui passent la moitié de leur vie à quatre pattes. Odorat inégalé. Souvent trouvés en extase près des vestiaires ou dans les transports aux heures de pointe. Classés H dans l'Union (peuvent légalement être transformés en côtelettes).

## Signe Racial
- **Quasi-télépathie** via TCHERNOBYL : peut lire les pensées enfouies dans la sueur/transpiration
- La cible doit effectivement transpirer ; le déodorant bloque le pouvoir
- Certains individus puent tellement que seules des grossièretés sont lisibles

## Effets mécaniques résumés
| Effet | Valeur |
|---|---|
| Télépathie par la sueur | Via TCHERNOBYL |
| Condition | Cible doit transpirer |
