# Alevin

> Source : Livre de base, p.92

## Description
Petit poisson pilotant un grand corps mécanique (poisson dans un bocal sécurisé dans une armure mech).

## Signe Racial
- Peut prendre les **Signes Raciaux de Robot** (sauf Défragmentation Accélérée)
- Mêmes règles de réparation que les robots (MACHINISTE)
- Peut sortir du mech pour opérer comme simple poisson en milieu aquatique, mais perd tous les Traits dépendants du mech et tombe à **1 PV**

## Effets mécaniques résumés
| Effet | Valeur |
|---|---|
| Signes Robot disponibles | Oui (sauf Défrag) |
| Soins | MACHINISTE |
| Hors mech | 1 PV, perd Traits mech |
